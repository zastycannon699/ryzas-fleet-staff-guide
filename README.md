# Ryza's Fleet Staff Guide

A standalone responsive staff punishment guide based only on the published Rule / Punishment / Escalation entries in the linked Notion sheet. It has no build step or dependencies.

## Run it

Open `index.html` in a browser, or serve the `ServerPolicyHub` directory with any static host.

## Customize it

- Replace the server name, contact email, and metadata in `index.html`.
- The published entries are stored at the top of `assets/app.js` as `rules`.
- Change the visual design tokens at the top of `assets/styles.css` to use your server colours.

The searchable and filterable policy table updates automatically from the policy list.
